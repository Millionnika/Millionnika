# Маршрут по проекту «Миллионика»

Это браузерная игра: Next.js/TypeScript, ASP.NET Core/.NET 10, PostgreSQL. Сначала открой [карту проекта](docs/PROJECT_MAP.md), затем читай только файлы по своей задаче. Для поиска используй `rg`; не обходи весь репозиторий ради знакомства.

- Текущее поведение определяет код. [ARCHITECTURE.md](docs/ARCHITECTURE.md) объясняет связи и ограничения, [STATUS.md](docs/STATUS.md) хранит сводку и историю, [COMBAT_SPEC.md](docs/COMBAT_SPEC.md) — правила боя. Исторические разделы могут описывать старое состояние.
- Перед изменениями проверь `git status --short` и сохраняй чужие незавершённые правки. Меняй только файлы, нужные задаче.
- Для визуальной задачи работай во frontend; игровую логику и базу меняй только если задача их требует. Боевые формулы рассчитывает сервер.
- Интеграционные тесты запускай только на отдельной базе `millionnika_tests` по инструкции в README. Не запускай их на рабочей базе `millionnika`.
- Перед рабочей миграцией проверь совместимость данных, сделай копию вне Git и проверь восстановление. Применённые миграции не переписывай.
- После изменения проверь подходящую сборку/тесты; для интерфейса проверь ПК и 390 px, если доступен браузер. В отчёте отделяй выполненные проверки от непроверенных.

Начни с раздела нужной системы в [PROJECT_MAP.md](docs/PROJECT_MAP.md). Подробные документы открывай по необходимости.
